# 📊 Sales Analysis Dashboard | Power BI

## 📌 Project Overview

Developed an interactive Power BI dashboard to analyze sales performance and business profitability.

## 📈 Key Metrics & Visualizations

- **KPI Cards:** Total Profit, Total Units Sold, Total COGS, and Growth Rate.
- **Revenue Trend:** Tracks revenue over time.
- **Sales by Region:** Compares regional sales performance.
- **Product Performance:** Analyzes sales across products.
- **Profit by Category:** Evaluates profitability by product category.

## ✨ Features / Highlights

- Provides an overview of key sales and profitability metrics.
- Identifies revenue trends and regional sales performance.
- Highlights product performance and profitable categories.
- Supports data-driven decisions on sales strategies and resource allocation.
- Helps businesses identify growth opportunities and areas for improvement.

## 🛠️ Tech Stack

- Microsoft Excel — Data Cleaning
- Microsoft Power BI — Data Visualization
- DAX — Calculated Measures
